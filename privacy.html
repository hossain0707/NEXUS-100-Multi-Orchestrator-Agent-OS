NEXUS-100 Privacy Policy

Effective: October 1, 2026

NEXUS-100 is a read-only AI orchestration and model-strategy service. This policy describes the data processed by the public NEXUS-100 plugin and its remote MCP server.

Data we process

When you use NEXUS-100, the service receives the task text and parameters that ChatGPT or another MCP client sends to a selected tool. The public marketplace tools do not request passwords, API keys, payment card data, government identifiers, health records, or other restricted credentials.

How data is used

Task text is used only to calculate domain routing, specialist-agent selection, model-strategy recommendations, token budgets, and related read-only results. NEXUS-100 does not use marketplace tool inputs for advertising, behavioral profiling, or sale to data brokers.

Model providers

The public marketplace tools do not send your task text to a model provider for paid inference. The server may query a configured model provider's model-list endpoint using server-owned credentials to refresh the available model catalog; that catalog refresh does not include your task text.

Storage and retention

The public marketplace MCP tools are designed to be stateless and do not intentionally persist user task text after the response is produced. Application-level marketplace tools do not create user profiles or store conversation histories. Cloud hosting may generate ordinary security and access logs. Such operational logs are retained for no more than 30 days unless a longer period is required to investigate abuse, comply with law, or protect the service.

Sharing

Data may be processed by infrastructure providers strictly to operate and secure the service. We do not sell personal data. We do not intentionally disclose task content to unrelated third parties.

Your controls

You control what information you send to the plugin. Do not include secrets or sensitive personal data that are not necessary for the routing task. You can stop using or disconnect the plugin at any time.

Security

We use HTTPS transport, narrowly scoped read-only marketplace tools, explicit MCP safety annotations, and server-side separation between public planning tools and protected control-plane operations.

Children

NEXUS-100 is a general developer and productivity tool and is not directed to children under the minimum age required by applicable law or the ChatGPT service used to access it.

Changes

If the service begins collecting materially different data or adds authenticated or write capabilities, this policy will be updated before those capabilities are published to marketplace users.

Contact

For privacy questions, use the NEXUS-100 support page or repository issue tracker.
