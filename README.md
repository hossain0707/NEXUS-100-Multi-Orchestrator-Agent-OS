# NEXUS-100 — Multi-Orchestrator Agent OS

Interactive architecture preview for a hierarchical multi-orchestrator AI system with **100 specialist agents across 10 domains**.

## Architecture

- Global Meta Orchestrator for intent, planning, routing and reconciliation
- 10 domain orchestrators with 10 specialist agents each
- Global event bus for controlled cross-domain communication
- Memory fabric for task, domain, semantic and audit history
- RBAC/tool scopes, budget governance and human approval gates
- Dynamic activation: only the agents required for a mission need to run

## Interactive Preview

Open `index.html` or use the GitHub Pages deployment after Pages is enabled for this repository.

The current preview simulates mission planning, cross-domain routing, scheduling, approval gating and a live event stream.

## Status

This repository currently contains the **interactive architecture preview**. The UI represents the target production architecture; it is not a claim that all 100 agents and external integrations are already running as backend services.
