Before reporting

Please include the affected tool name, expected behavior, actual behavior, and whether the issue occurs in ChatGPT, Codex, or the public dashboard. Do not post API keys, passwords, access tokens, or other secrets.

Security issues

For security-sensitive reports, do not include secrets or exploit payloads in a public issue. Start with a minimal description and request a private follow-up channel.
